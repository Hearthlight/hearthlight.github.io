# Security

Please report security vulnerabilities through GitHub's private vulnerability reporting:
[Report a vulnerability](https://github.com/Hearthlight/hearthlight.github.io/security/advisories/new).
This reporting channel will be enabled for the public release. If it is not available yet,
do not publish exploit details or secrets in a public issue.

Include the affected version, the expected and observed behavior, and a minimal reproduction
against your own local instance. Do not run denial-of-service or saturation tests against the
hosted relay or other players' parties.

Only the latest release is maintained. Dependency updates and relay security checks run in CI.
Keep local environment files, credentials and server logs out of commits. Use GitHub's
`noreply` address if you want to keep your personal email out of commit metadata.
